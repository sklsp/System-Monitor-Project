This project displays live hardware and system statistics such as CPU, RAM, disk usage, network activity, and more through a clean desktop interface.

Features:


Current Features:

CPU Load, Cores. Freq,
RAM Usage, Total, Swap,
Disk Writing, Reading, Total/Used/Free,
GPU Load, Memory, Name,
Ethernet, Link speed, Upload/Download Usage,
Current processes,
Basic graphs,
Real-time refresh updates,
Clean dark mode UI.
